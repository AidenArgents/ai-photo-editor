# AI Photo Editor / 电商 AI 工具台

这是一个在自己电脑上运行的 AI 图片工具。

程序打开后运行在：

```text
http://localhost:3000
```

每位用户需要在页面右上角填写自己的 Gemini API Key。

## 第一次使用（推荐）

不需要提前安装 Git、Node.js，也不需要输入命令。

1. 打开项目页面：

   https://github.com/AidenArgents/ai-photo-editor

2. 点击绿色的 `Code`，再点击 `Download ZIP`。
3. 把 ZIP 解压到想存放程序的位置。
4. 打开解压后的文件夹，双击：

```text
初始化.bat
```

安装程序会自动：

- 检查电脑环境；
- 缺少 Git 或 Node.js 时，下载项目专用的便携版本；
- 准备以后需要的一键更新功能；
- 安装项目依赖；
- 启动程序并打开浏览器。

便携运行环境只保存在项目自己的 `.runtime` 文件夹，不会安装到 Windows 系统。

安装过程中需要保持网络连接。第一次安装下载内容较多，请等待窗口显示完成。

### 填写 API Key

在页面右上角填写自己的 Gemini API Key，即可开始使用。

API Key 只保存在当前电脑的浏览器中，不会随项目上传。

## Web 模式与 API 模式

项目已经合并为一个 `ai-photo-editor`，不再需要分别打开 Web 版和 API 版。

页面左上角可以切换整套工具的运行模式：

- `Web 网页模式`（默认）：最终作图由 Ianto 自动调用已登录的 Gemini 或 ChatGPT 网页，上传任务图片并把成图回传到本工具；
- `API 模式`：保留原有 Gemini / OpenAI 图片 API 模型和原有页面逻辑。

第一页可在顶部选择 `Gemini 网页版` 或 `ChatGPT 网页版`。FBA、套图、主图和场景图页面也各自提供同样的生图下拉选项。Web 模式只改变最终作图出口；页面原有的产品录入、市场、语言、方案和提示词流程继续保留。

Web 模式需要：

1. 安装或更新到 Ianto 2.6.0；
2. 在 Chrome 中登录准备使用的 Gemini 或 ChatGPT 网页；
3. 重载 Ianto 后刷新本工具。

Ianto 只复用浏览器当前已有的登录状态，不读取或保存账号密码、Cookie。ChatGPT 网页作图是否可用及使用额度由用户自己的 ChatGPT 方案和工作区决定。

## `初始化.bat` 和 `安装.bat` 的区别

### `初始化.bat`：第一次使用

第一次把程序下载到电脑后，优先双击 `初始化.bat`。

它负责完整的首次准备工作：

- 检查 Git 和 Node.js；
- 缺少时下载项目专用的便携版本；
- 让 Download ZIP 得到的文件夹也能使用 `更新.bat`；
- 安装项目依赖；
- 启动程序并打开浏览器。

### `安装.bat`：安装或修复依赖

`安装.bat` 用于项目文件夹已经准备好的情况。

它会：

- 检查并准备 Git 和 Node.js；
- 安装或修复 `node_modules` 项目依赖。

它不会重新下载项目，也不会启动程序。运行完成后，需要再双击 `启动.bat`。

通常情况下：

- 第一次使用：运行 `初始化.bat`；
- 依赖损坏或安装不完整：运行 `安装.bat`；
- 平时打开程序：运行 `启动.bat`。

### 更新程序

双击：

```text
更新.bat
```

更新工具会**自动检测 GitHub 上的新版本并下载**，然后自动完成替换和重启，全程不需要 Git 命令。

更新过程：

- 对比本地版本号与 GitHub 最新版本号，有新版才下载；
- 下载走 Windows 系统代理（与浏览器一致），失败会自动尝试镜像加速地址；
- **覆盖合并**：新版覆盖同名文件，本地修改或生成的文件（zip 包之外的）不会被删除；
- 新版自带全部依赖，无需手动安装；
- 下载约 30 MB，网速正常时 1-5 分钟完成。

如果窗口提示更新失败，请先确认网络/系统代理可用（浏览器能打开 GitHub 即可），然后重新双击 `更新.bat`。本地现有版本不受影响，可继续使用。

### 页面没有自动打开

先确认已经运行 `启动.bat`，然后在浏览器中打开：

```text
http://localhost:3000
```

### 更新提示当前目录不是 Git clone

如果最初是直接解压 ZIP，先在项目文件夹双击 `初始化.bat`。它会把当前文件夹准备成可更新的 Git 安装；完成后再双击 `更新.bat`。

### 显示 `fetch failed` 或无法连接 Gemini

这表示页面和本地服务已经启动，但这台电脑无法连接 Google 的 Gemini API。

如果使用代理软件：

1. 开启代理软件的“系统代理”或“TUN/虚拟网卡模式”；
2. 仅安装在浏览器里的代理扩展不能供本地服务使用；
3. 双击 `重启.bat`，让程序重新读取代理设置；
4. 再次生成图片。

程序启动时会自动读取 Windows 系统代理。详细的底层网络错误保存在项目文件夹的 `server.log` 中。

### 修改 API Key

直接在页面右上角重新填写即可。
